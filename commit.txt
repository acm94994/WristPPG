Add full ANC pipeline: all methods, scoring and Viterbi HR tracker

Data and preprocessing
- load.py: reads Wrist PPG During Exercise (PPG, ±16 g accel, gyro,
  ECG R peaks), trims NaN padding, parses subject/activity
- preprocess.py: resample to 64 Hz (20/35 Hz for reproductions),
  0.4–4 Hz band-pass, 8 z-scored references (acc xyz, gyro xyz, |a|, |w|),
  forearm-axis detection

Methods (src/methods.py, one entry point: run_method)
- RAW, LMS-HK (Han & Kim reproduction), NLMS-FV (Fallet & Vesin
  reproduction), NLMS-1, NLMS-all, RLS-all, CW-NLMS
- CW-NLMS: per-window MSC weights (coherence.py) with threshold tau
  and variable step size
- filters.py: LMS/NLMS with multi-channel, per-channel weights and
  per-sample mu; NLMS bank; RLS (lambda = 0.999)

HR estimation and scoring
- hr.py: harmonic sum, IMU motion-harmonic suppression, Viterbi path
  tracking (PPG + IMU only, never ECG)
- score.py: ECG HR per window matched by time; the only module using ECG

Tools and docs
- demo.py (smoke test), diag.py (spectrogram diagnostics)
- README with interfaces and the run loop for B; DECISIONS.md log

Untuned run on all 19 records: every filter beats raw PPG on average;
multi-reference NLMS gives the largest gain on running.
